# Contributing

## Getting Started

```bash
git clone https://github.com/omiinaya/books-sqz.git
cd books-sqz
npm install
```

## Development

- **Dev:** `npm run dev`
- **Build:** `npm run build`
- **Lint:** `npm run lint`
- **Test:** `npm test`

## Commit Messages

```
type: concise subject
```

Types: `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`, `test:`
